# benday launch video

A 30-second Remotion composition built from benday's real dot-map bake, presets, logo component, typefaces, grayscale tokens and hero artwork.

```bash
bun run video:studio
bun run video:still
bun run video:render
```

`BendayLaunch` renders at 1920×1080, 60fps. The final silent H.264 file is written to `apps/launch-video/out/benday-launch.mp4`, ready for audio post-production.
