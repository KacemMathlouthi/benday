# Contact

benday is a one-maintainer open-source project, and everything about it happens in public on the repository.

## Bugs and preset ideas

Open an issue: <https://github.com/KacemMathlouthi/benday/issues>. That is the right place for a logo that bakes badly, a preset that misbehaves at small sizes, or a prop that does not do what the documentation says. Include the logo, or the JSX the playground generated for it: the bake is determined entirely by the source image and the options, so that is enough to reproduce it.

## Code

Pull requests go to <https://github.com/KacemMathlouthi/benday>. `CONTRIBUTING.md` covers the setup, the changeset a user-facing change needs, and the checks CI runs. Open questions that are not yet a bug fit best in the repository's discussions.

## The maintainer

benday is built by Kacem Mathlouthi, reachable at <https://x.com/KacemMathlouthi>, on GitHub at <https://github.com/KacemMathlouthi>, and through his site at <https://kacemmathlouthi.dev>. There is no support contract and no mailing list: issues are answered in the open, where the next person with the same question can find the answer.
